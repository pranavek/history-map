About this map

This is a map of historical places in India, built one region at a time. Every place is a pin, typed by what kind of place it is, filterable by era and by theme, and required to cite where its history came from.

It covers several states so far. What is on it is a function of what has been added, not a judgement about what matters — the gaps are gaps, not statements.

What is on it

What a place has to have

  • A source. Every place cites where its history came from. Nothing ships unsourced — the data loader refuses to start if a place has no sources.
  • A type and an era. The pin's shape and colour come from what kind of place it is; the era is a separate axis, because a temple and a mosque from the same century belong together in time but not in kind.
  • Honest uncertainty. Where the record is contested, the entry says so rather than picking the tidier story.

Things this map admits it does not know

This list is generated from the data itself rather than written by hand, so it cannot quietly fall out of date. Every entry below is a place whose record is genuinely unsettled, quoted from its own notes.

    Built with

    • Leaflet for the map, loaded from a CDN.
    • Tiles from OpenStreetMap, whose style is CC0, given a parchment treatment in CSS.
    • No build step, no framework, no dependencies. Plain HTML, one stylesheet, a few ES modules.
    • This site's own code sets no cookies and loads no analytics. Note that the CDN in front of it injects a Cloudflare Insights beacon into pages served to browsers — that is added in transit, not by anything in this repository.

    Contributing a place

    Add an entry to data/places/<region>.json and, for a new region, a line in data/regions.json. No code changes are needed. The loader validates every category, era and tag against the controlled vocabularies and fails loudly on anything it does not recognise.
